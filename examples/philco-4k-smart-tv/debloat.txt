# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/philco-4k-smart-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/philco-4k-smart-tv/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher (the scripts' default); HOME candidates on stock are
# only tvlauncher (priority 2) and com.android.tv.settings/.system.FallbackHome. setupwraith's
# RecoveryActivity does NOT claim HOME on this firmware (verified 2026-10-20 with
# `cmd package query-activities -c android.intent.category.HOME`), so setupwraith stays ENABLED on
# purpose: no Home takeover risk, no Wi-Fi loss, casting credentials untouched.
# Live TV: com.mediatek.wwtv.tvcenter. TV inputs: com.mediatek.tvinput (tuners + HDMI).
# Saved Wi-Fi networks at test time: RODRIGUES OI FIBRA 2G / RODRIGUES SALA (owner not checked,
# irrelevant while setupwraith is kept).
#
# KEEP, even though the names look like bloat:
# - fusion.android.tv.demo: on the MTC-built Hitachi 65QLEDSM20 the same package ("MtcRetailDisplay")
#   handles the remote's Input button (TV_INPUT_BUTTON) and Bluetooth pairing; it does not loop on
#   this set. Disable only if a retail demo loop shows up, and re-enable if Input stops working.
# - com.mediatek.leanbacklauncher.partnercustomizer (+ .overlay): provides the tvlauncher.widget
#   provider that com.mediatek.tv.service needs after a reboot (see examples/chiq-ai-pont).
# - com.mediatek.* (tv.service, tvinput, tvcenter, mediaplayer, network, autopair, wwtv.*):
#   inputs, tuners and Live TV; com.dolby.android.audio.service: audio processing.
# - com.ktc.tv.factory, ktc.factorymenu.ui, mediatek.factorymenu.ui, com.ktc.serialport:
#   factory/panel menus used for service; com.mstar.android.tv.disclaimercustomization kept for now.
# - com.google.android.apps.mediashell (Chromecast receiver), com.google.android.tv.remote.service
#   (phone remote), com.google.android.marvin.talkback (accessibility).
# - Netflix (com.netflix.ninja), YouTube (com.google.android.youtube.tv), Google Assistant
#   (com.google.android.katniss + com.google.android.tv.assistant): all kept by choice 2026-10-20.
# - android.autoinstalls.config.ktc.pai is the KTC Play Auto Install config: disabled below, like
#   android.autoinstalls.config.JVC on the Hitachi/MTC lists.
#
